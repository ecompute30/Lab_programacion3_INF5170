# Práctica 8 — Modelo MVC

Presentación reveal.js (construida con la skill `/html-slides`) que investiga el patrón
**Modelo-Vista-Controlador**: su origen en Smalltalk-80 (Trygve Reenskaug, Xerox PARC, 1979),
los tres componentes, ventajas/desventajas, por qué sigue vigente, cómo lo adaptan frameworks
modernos (Spring MVC, ASP.NET MVC, Laravel, Django, Rails) y un ejemplo de registro de
estudiantes — incluyendo una versión en código que reutiliza la Práctica 7 (CRUD de tareas)
para mostrar MVC "en la práctica" con código ya escrito en este mismo repositorio.

Ver [`index.html`](index.html).
