¿Qué es Spring Framework?

Spring es un framework de código abierto para Java, creado por Rod Johnson en 2003, orientado al desarrollo de aplicaciones empresariales.

Su idea central es la Inversión de Control (IoC) y la Inyección de Dependencias (DI): en vez de que cada clase cree sus propias dependencias, Spring las "inyecta" desde un contenedor central.

Características y ventajas

  • Contenedor de IoC / Inyección de Dependencias
  • Basado en POJOs (objetos Java simples, sin herencias forzadas)
  • Programación Orientada a Aspectos (AOP) para logging, transacciones, seguridad
  • Altamente modular: se usa solo lo que se necesita
  • Se integra con casi cualquier tecnología (JDBC, JPA, mensajería, testing)
  • Facilita las pruebas unitarias al desacoplar dependencias

Módulos más importantes

MóduloPara qué sirve
Spring CoreEl contenedor de IoC / Inyección de Dependencias; base de todo lo demás.
Spring MVCImplementación del patrón MVC (Práctica 8) para aplicaciones web y APIs REST.
Spring BootAuto-configuración y arranque rápido: convierte días de configuración en minutos.
Spring DataSimplifica el acceso a bases de datos (JPA, MongoDB...) con repositorios casi sin código.
Spring SecurityAutenticación y autorización (login, roles, JWT, OAuth2) de forma declarativa.

Spring Core + Spring MVC, en código


@Component // Spring gestiona el ciclo de vida de esta clase (Core/IoC)
public class TareaService { /* lógica de negocio, el "Modelo" */ }

@RestController // Spring MVC: expone un controlador HTTP
@RequestMapping("/api/tareas")
public class TareaController {
    @Autowired private TareaService servicio; // Inyección de Dependencias

    @PostMapping
    public Tarea crear(@RequestBody Tarea tarea) {
        return servicio.guardar(tarea); // mismo flujo que vimos en la Práctica 7
    }
}

Usos reales de Spring

  • Sistemas bancarios y de seguros: transacciones complejas, alta necesidad de seguridad (Spring Security) y de auditoría.
  • E-commerce a gran escala: catálogos, pedidos y pagos sobre Spring Boot + Spring Data.
  • Microservicios empresariales: Spring Boot + Spring Cloud son el estándar de facto para arquitecturas de microservicios en Java.
  • Empresas como Netflix popularizaron patrones de microservicios que se integran de forma nativa con el ecosistema Spring.

Conclusión personal

Spring no inventó la Inyección de Dependencias ni el patrón MVC — los popularizó y los empaquetó de forma productiva para el ecosistema Java empresarial. Entender primero los conceptos base (MVC, IoC) antes que la "magia" de Spring Boot hace que sus anotaciones (@Autowired, @RestController) se sientan como atajos razonados, no como sintaxis memorizada sin entender qué resuelven.
