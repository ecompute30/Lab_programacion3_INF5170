🪪 Validador de Cédula Dominicana

Práctica 9 — Servicios Web. Valida el dígito verificador con el algoritmo del módulo 10 y lo contrasta con la API oficial del gobierno dominicano.

    ¿Cómo funciona?

    1. Escribe los 11 dígitos de la cédula; el formato 000-0000000-0 se aplica automáticamente.
    2. El servidor calcula el dígito verificador con el algoritmo del módulo 10 sobre los primeros 10 dígitos.
    3. Además, consulta la API oficial del gobierno como referencia (puede no estar disponible en todo momento; en ese caso solo se muestra el resultado local).
