102 Etiquetas HTML

Referencia con número, nombre, descripción, ejemplo de uso y un dato adicional por etiqueta.

# Etiqueta Descripción Ejemplo de uso Elemento adicional
1 <html> Elemento raíz que envuelve todo el documento HTML. <html lang="es">...</html> El atributo lang ayuda a lectores de pantalla y motores de búsqueda a identificar el idioma.
2 <head> Contiene los metadatos del documento; no se muestra directamente en la página. <head><title>Mi página</title></head> Debe incluir siempre al menos un <title>.
3 <title> Define el título de la página, visible en la pestaña del navegador. <title>Mi sitio web</title> Es fundamental para SEO y para guardar la página como favorito.
4 <body> Contiene todo el contenido visible de la página. <body><h1>Hola</h1></body> Solo puede haber un <body> por documento.
5 <meta> Define metadatos como codificación, autor o descripción de la página. <meta charset="UTF-8"> meta name="viewport" es clave para el diseño responsivo.
6 <link> Enlaza recursos externos, como hojas de estilo o iconos. <link rel="stylesheet" href="styles.css"> También se usa para favicons con rel="icon".
7 <style> Define estilos CSS internos dentro del documento. <style>body{color:blue;}</style> Para proyectos grandes se recomienda usar CSS externo.
8 <script> Incrusta o referencia código JavaScript. <script src="app.js"></script> El atributo defer evita bloquear el renderizado de la página.
9 <noscript> Muestra contenido alternativo cuando JavaScript está deshabilitado. <noscript>Activa JavaScript para continuar.</noscript> Útil como mensaje de respaldo accesible.
10 <base> Define la URL base para todas las rutas relativas del documento. <base href="https://miweb.com/"> Solo puede haber un <base> por documento.
11 <div> Contenedor genérico de bloque, sin significado semántico propio. <div class="tarjeta">Contenido</div> Se usa mucho junto con CSS, Flexbox o Grid.
12 <span> Contenedor genérico en línea, sin significado semántico propio. <span style="color:red">Texto</span> Ideal para aplicar estilos a una parte de un texto.
13 <p> Define un párrafo de texto. <p>Este es un párrafo.</p> Puede contener elementos en línea como <a> o <strong>.
14 <h1> Encabezado de mayor importancia en la página. <h1>Título principal</h1> Idealmente debe usarse una sola vez por página.
15 <h2> Encabezado de segundo nivel de importancia. <h2>Subtítulo</h2> Ayuda a estructurar jerárquicamente el contenido.
16 <h3> Encabezado de tercer nivel de importancia. <h3>Sección</h3> Se anida lógicamente dentro de un <h2>.
17 <h4> Encabezado de cuarto nivel de importancia. <h4>Subsección</h4> Útil en documentos con jerarquías profundas.
18 <h5> Encabezado de quinto nivel de importancia. <h5>Detalle</h5> Poco usado; suele bastar con h1-h3.
19 <h6> Encabezado de menor jerarquía disponible en HTML. <h6>Nota</h6> Los seis niveles (h1-h6) permiten estructurar el contenido.
20 <hr> Dibuja una línea horizontal que representa un cambio temático. <hr> Es un elemento vacío: no tiene etiqueta de cierre ni contenido.
21 <br> Inserta un salto de línea dentro de un bloque de texto. Línea uno<br>Línea dos No debe usarse para dar espaciado; para eso se usa CSS.
22 <pre> Muestra texto preformateado, respetando espacios y saltos de línea. <pre> Código con espacios</pre> Muy usado junto con <code> para mostrar bloques de código.
23 <blockquote> Define una cita larga proveniente de otra fuente. <blockquote cite="https://fuente.com">Cita textual</blockquote> El atributo cite indica la URL de la fuente original.
24 <address> Proporciona información de contacto del autor o dueño del documento. <address>Contacto: correo@ejemplo.com</address> Por defecto el navegador la muestra en cursiva.
25 <ol> Define una lista ordenada (numerada). <ol><li>Uno</li><li>Dos</li></ol> El atributo start permite definir el número inicial.
26 <ul> Define una lista desordenada (con viñetas). <ul><li>Manzana</li><li>Pera</li></ul> Se estiliza comúnmente quitando las viñetas con CSS.
27 <li> Define un elemento dentro de una lista (ol, ul o menu). <li>Elemento de lista</li> Solo es válido dentro de <ul>, <ol> o <menu>.
28 <dl> Define una lista de descripción (términos y sus definiciones). <dl><dt>HTML</dt><dd>Lenguaje de marcado</dd></dl> Ideal para glosarios o preguntas frecuentes.
29 <dt> Define el término dentro de una lista de descripción. <dt>CSS</dt> Debe usarse dentro de un elemento <dl>.
30 <dd> Define la descripción o valor de un término en una <dl>. <dd>Lenguaje de estilos</dd> Puede contener varios párrafos de explicación.
31 <figure> Agrupa contenido multimedia junto con su leyenda. <figure><img src="foto.jpg" alt="Foto"><figcaption>Una foto</figcaption></figure> Se relaciona semánticamente con <figcaption>.
32 <figcaption> Define la leyenda o descripción de un <figure>. <figcaption>Descripción de la imagen</figcaption> Debe ser el primer o el último hijo de <figure>.
33 <main> Define el contenido principal y único del documento. <main><h1>Contenido</h1></main> Solo debe existir un <main> visible por página.
34 <a> Define un hipervínculo hacia otra página o recurso. <a href="https://example.com">Visita Ejemplo</a> target="_blank" abre el enlace en una nueva pestaña.
35 <em> Da énfasis, con carga semántica, al texto (se muestra en cursiva). <em>Texto enfatizado</em> A diferencia de <i>, sí aporta significado al contenido.
36 <strong> Indica texto de gran importancia (se muestra en negrita). <strong>Advertencia importante</strong> Se recomienda sobre <b> por motivos de accesibilidad.
37 <small> Representa texto en letra pequeña, como notas legales. <small>Términos y condiciones</small> Muy común en pies de página.
38 <s> Marca texto que ya no es preciso o relevante (tachado). <s>Precio anterior: $50</s> Distinto de <del>, que indica una edición del documento.
39 <cite> Referencia el título de una obra creativa (libro, película, etc.). <cite>Cien años de soledad</cite> No debe usarse para nombres de personas.
40 <q> Define una cita corta en línea. <q>Esto es una cita corta</q> El navegador añade las comillas automáticamente.
41 <dfn> Marca la definición de un término dentro del texto. <dfn>HTML</dfn> es un lenguaje de marcado. Suele combinarse con el atributo title.
42 <abbr> Define una abreviatura o acrónimo. <abbr title="HyperText Markup Language">HTML</abbr> El atributo title muestra el significado al pasar el mouse.
43 <ruby> Define anotaciones fonéticas, usadas típicamente en textos asiáticos. <ruby>漢<rt>Kan</rt></ruby> Se usa junto con <rt> y <rp>.
44 <rt> Define el texto de la anotación dentro de un elemento <ruby>. <rt>Kan</rt> Debe estar contenido dentro de <ruby>.
45 <rp> Define paréntesis de respaldo para navegadores sin soporte de ruby. <rp>(</rp> Se usa junto a <rt> y <ruby>.
46 <data> Asocia un valor legible por máquina a contenido legible por humanos. <data value="2024-01-01">1 de enero</data> Útil para metadatos que luego procesa JavaScript.
47 <time> Representa una fecha u hora específica. <time datetime="2026-09-18">18 de septiembre</time> El atributo datetime ofrece un formato estándar para máquinas.
48 <code> Representa un fragmento de código informático. <code>console.log("Hola")</code> Frecuentemente combinado con <pre> para bloques de código.
49 <var> Representa una variable en una expresión matemática o de programación. <var>x</var> = 5 Se muestra en cursiva por defecto.
50 <samp> Representa la salida de un programa o sistema informático. <samp>Archivo no encontrado</samp> Suele usarse junto con <kbd> y <code>.
51 <kbd> Representa una entrada de teclado realizada por el usuario. Presiona <kbd>Ctrl</kbd> + <kbd>C</kbd> Muy usado en tutoriales y documentación técnica.
52 <sub> Define texto en subíndice. H<sub>2</sub>O Común en fórmulas químicas.
53 <sup> Define texto en superíndice. X<sup>2</sup> Común en notas al pie y potencias matemáticas.
54 <i> Representa texto en cursiva, generalmente sin énfasis semántico. <i>Nombre científico</i> Útil para términos técnicos o en otro idioma.
55 <b> Representa texto en negrita sin implicar mayor importancia semántica. <b>Palabra clave</b> Para importancia semántica se recomienda <strong>.
56 <u> Subraya el texto, normalmente para indicar una anotación no textual. <u>Texto subrayado</u> Evitar usarlo para simular enlaces; puede confundir al usuario.
57 <mark> Resalta texto por relevancia contextual, como en resultados de búsqueda. <mark>Coincidencia</mark> encontrada Por defecto se muestra con fondo amarillo.
58 <bdi> Aísla un texto que puede tener una dirección de escritura distinta. <bdi>اسم</bdi> Útil cuando se mezclan idiomas RTL y LTR.
59 <bdo> Sobrescribe la dirección de escritura del texto. <bdo dir="rtl">Texto invertido</bdo> El atributo dir puede ser "ltr" o "rtl".
60 <wbr> Sugiere un punto donde el navegador puede insertar un salto de línea. super<wbr>califragilisticoso Útil para palabras muy largas o URLs.
61 <img> Incrusta una imagen en la página. <img src="imagen.jpg" alt="Descripción de la imagen"> El atributo alt es esencial para accesibilidad y SEO.
62 <iframe> Incrusta otra página o documento dentro de la actual. <iframe src="https://example.com"></iframe> El atributo sandbox mejora la seguridad al restringir permisos.
63 <embed> Incrusta contenido externo o un plugin en la página. <embed src="archivo.pdf" type="application/pdf"> Su uso ha disminuido a favor de <object> o <iframe>.
64 <object> Incrusta un recurso externo, como un PDF o una aplicación. <object data="archivo.pdf" type="application/pdf"></object> Puede contener contenido de respaldo entre sus etiquetas.
65 <param> Define parámetros para un elemento <object>. <param name="autoplay" value="true"> Debe colocarse siempre dentro de <object>.
66 <video> Incrusta contenido de video en la página. <video src="video.mp4" controls></video> El atributo controls muestra los controles de reproducción.
67 <audio> Incrusta contenido de audio en la página. <audio src="cancion.mp3" controls></audio> Puede combinarse con varias etiquetas <source>.
68 <source> Especifica múltiples fuentes de medios para video, audio o picture. <source src="video.webm" type="video/webm"> El navegador elige la primera fuente compatible.
69 <track> Agrega subtítulos o pistas de texto a un video. <track src="subs.vtt" kind="subtitles" srclang="es"> Mejora la accesibilidad del contenido multimedia.
70 <map> Define un mapa de imagen con áreas clicables. <map name="mapa"><area shape="rect" coords="0,0,100,100" href="link.html"></map> Se vincula a una imagen mediante el atributo usemap.
71 <area> Define una zona clicable dentro de un elemento <map>. <area shape="circle" coords="50,50,40" href="pagina.html" alt="Zona"> Requiere el atributo alt para accesibilidad.
72 <picture> Permite mostrar distintas imágenes según el dispositivo o pantalla. <picture><source srcset="grande.jpg" media="(min-width:800px)"><img src="pequena.jpg"></picture> Ideal para diseño responsivo de imágenes.
73 <canvas> Proporciona un área para dibujar gráficos mediante JavaScript. <canvas id="miCanvas" width="200" height="100"></canvas> Se dibuja usando la API Canvas de JavaScript.
74 <template> Define contenido HTML que no se renderiza hasta ser activado por JavaScript. <template id="miPlantilla"><p>Contenido oculto</p></template> Muy usado en componentes web reutilizables.
75 <slot> Define un espacio reservado dentro de un Web Component. <slot name="titulo"></slot> Se usa junto con Shadow DOM y <template>.
76 <ins> Marca texto que ha sido insertado o agregado a un documento. <ins>Texto nuevo agregado</ins> Por defecto se muestra subrayado.
77 <del> Marca texto que ha sido eliminado de un documento. <del>Texto eliminado</del> Por defecto se muestra tachado.
78 <table> Define una tabla de datos. <table><tr><td>Dato</td></tr></table> Se recomienda usar <thead>, <tbody> y <tfoot> para estructurarla.
79 <caption> Define el título de una tabla. <caption>Horario de clases</caption> Debe ser el primer elemento hijo de <table>.
80 <colgroup> Agrupa columnas de una tabla para aplicarles estilos en conjunto. <colgroup><col span="2" style="background:#eee"></colgroup> Se coloca justo después de <caption>.
81 <col> Define las propiedades de una columna dentro de un <colgroup>. <col style="width:150px"> No tiene contenido, solo atributos.
82 <tbody> Agrupa el contenido principal (cuerpo) de una tabla. <tbody><tr><td>Dato</td></tr></tbody> Permite aplicar scroll independiente al cuerpo de la tabla.
83 <thead> Agrupa las filas de encabezado de una tabla. <thead><tr><th>Nombre</th></tr></thead> Se estiliza normalmente con un fondo distinto.
84 <tfoot> Agrupa las filas de pie de una tabla. <tfoot><tr><td>Total</td></tr></tfoot> Puede escribirse antes de tbody, pero se renderiza al final.
85 <tr> Define una fila dentro de una tabla. <tr><td>Celda 1</td><td>Celda 2</td></tr> Puede contener celdas <td> o <th>.
86 <td> Define una celda de datos estándar dentro de una fila de tabla. <td>Información</td> El atributo colspan permite unir varias columnas.
87 <th> Define una celda de encabezado dentro de una tabla. <th>Nombre</th> El atributo scope mejora la accesibilidad (fila o columna).
88 <form> Define un formulario para recolectar datos del usuario. <form action="/enviar" method="post"></form> El atributo method define si se envía por GET o POST.
89 <label> Define una etiqueta descriptiva para un control de formulario. <label for="nombre">Nombre:</label> El atributo for debe coincidir con el id del input relacionado.
90 <input> Define un campo de entrada de datos en un formulario. <input type="email" placeholder="tu@correo.com"> El atributo type cambia su comportamiento (text, email, checkbox, etc.).
91 <button> Define un botón interactivo. <button type="submit">Enviar</button> type="button" evita que envíe el formulario por accidente.
92 <select> Define una lista desplegable de opciones. <select><option>Uno</option><option>Dos</option></select> El atributo multiple permite seleccionar varias opciones.
93 <datalist> Define una lista de opciones predefinidas para un <input>. <input list="opciones"><datalist id="opciones"><option value="Rojo"></datalist> Ofrece autocompletado sin restringir la escritura libre.
94 <optgroup> Agrupa opciones relacionadas dentro de un <select>. <optgroup label="Frutas"><option>Manzana</option></optgroup> El atributo label define el título del grupo.
95 <option> Define una opción dentro de select, optgroup o datalist. <option value="do">República Dominicana</option> El atributo selected marca la opción por defecto.
96 <textarea> Define un campo de texto multilínea. <textarea rows="4" cols="30">Escribe aquí...</textarea> A diferencia de input, permite varias líneas de texto.
97 <output> Muestra el resultado de un cálculo o acción del usuario. <output name="resultado">42</output> Suele actualizarse dinámicamente mediante JavaScript.
98 <progress> Muestra el progreso de una tarea, como una descarga. <progress value="70" max="100"></progress> Sin el atributo value, muestra una barra indeterminada.
99 <meter> Muestra una medición dentro de un rango conocido, como el nivel de batería. <meter value="0.6" min="0" max="1"></meter> A diferencia de progress, representa una medida, no un avance.
100 <fieldset> Agrupa controles relacionados dentro de un formulario. <fieldset><legend>Datos personales</legend></fieldset> Ayuda a organizar visualmente formularios largos.
101 <legend> Define el título de un elemento <fieldset>. <legend>Información de contacto</legend> Debe ser el primer hijo del fieldset.
102 <details> Crea un widget desplegable que el usuario puede abrir o cerrar. <details><summary>Ver más</summary><p>Contenido oculto</p></details> Se usa junto con <summary> para definir el título visible.
