¿Qué es XML?

XML (eXtensible Markup Language) es un lenguaje de marcado creado por el W3C en 1998 para describir y estructurar información de forma jerárquica, usando texto plano y etiquetas definidas por quien lo usa.

A diferencia de HTML, que tiene etiquetas fijas para presentación (<p>, <table>...), en XML el autor del documento define sus propias etiquetas según el significado de los datos.

Propósito de XML

  • Representar datos estructurados y jerárquicos de forma independiente de la plataforma, el lenguaje de programación o la aplicación que los genera.
  • Ser legible tanto por humanos (es texto plano) como por máquinas (tiene una gramática formal y validable).
  • Permitir el intercambio de información entre sistemas distintos sin perder la estructura ni el significado de los datos.

Características principales

Estructurales

  • Jerárquico (estructura de árbol)
  • Un único elemento raíz
  • Etiquetas de apertura y cierre
  • Soporta atributos y namespaces

De diseño

  • Extensible: etiquetas definidas por el autor
  • Autodescriptivo
  • Validable con DTD o XSD (esquemas)
  • Separa datos de presentación

Usos actuales de XML

  • Servicios web SOAP
  • Feeds RSS / Atom
  • Configuración: pom.xml (Maven), web.config (.NET)
  • Layouts de Android (activity_main.xml)
  • Documentos Office (.docx/.xlsx son ZIPs de XML internamente)
  • EDI e integraciones en banca, salud y gobierno

Ejemplo de documento XML


<?xml version="1.0" encoding="UTF-8"?>
<biblioteca>
  <libro id="1" disponible="true">
    <titulo>Cien años de soledad</titulo>
    <autor>Gabriel García Márquez</autor>
  </libro>
</biblioteca>

Partes del documento

  • Prólogo (<?xml version="1.0"?>): declara la versión y codificación.
  • Elemento raíz (<biblioteca>): único, envuelve todo el documento.
  • Elemento hijo (<libro>): puede repetirse y anidarse.
  • Atributos (id="1", disponible="true"): metadatos del elemento.
  • Contenido de texto (<titulo>...</titulo>): el dato en sí.

En síntesis

XML sigue siendo clave donde se requiere validación estricta de esquema, namespaces y compatibilidad con sistemas empresariales maduros — aunque para APIs web modernas, JSON (siguiente presentación) lo ha desplazado por ser más ligero.
