¿Qué es AJAX?

AJAX (Asynchronous JavaScript And XML) no es un lenguaje ni una tecnología única, sino una técnica: usar JavaScript para hacer solicitudes HTTP en segundo plano, sin recargar la página completa.

El nombre incluye "XML" por su origen histórico (el objeto XMLHttpRequest, año 2005), pero hoy casi siempre se intercambia JSON en vez de XML — por eso vimos JSON justo antes.

Propósito de AJAX

  • Actualizar partes de una página sin recargarla por completo.
  • Reducir el tráfico de red: se transfieren solo los datos, no todo el HTML de nuevo.
  • Mejorar la experiencia de usuario con interfaces más fluidas y "tipo app".

¿Cómo funciona AJAX?

  1. El usuario realiza una acción (clic, escribir, seleccionar).
  2. JavaScript dispara una solicitud HTTP asíncrona (fetch o XMLHttpRequest).
  3. El navegador sigue respondiendo mientras se espera la respuesta.
  4. El servidor procesa la solicitud y responde (normalmente con JSON).
  5. JavaScript recibe la respuesta y actualiza el DOM con los nuevos datos.

Relación AJAX – JS – navegador – servidor

Navegador

JavaScript ejecuta fetch() ante un evento del usuario

⇄

Servidor / API

Procesa la solicitud y responde con datos (JSON)

El navegador nunca deja de mostrar la página actual: solo el fragmento de JS que hizo la solicitud se entera de la respuesta y decide qué parte del DOM actualizar.

Ventajas y desventajas

VentajasDesventajas
UX fluida, sin parpadeo de recarga completaDepende de JavaScript habilitado en el navegador
Menor consumo de ancho de banda (solo datos)Manejo del botón "atrás" requiere cuidado extra
Permite validaciones y búsquedas en tiempo realSEO más complejo si el contenido depende 100% de JS
Base de las SPA (Single Page Applications)Depuración más compleja (estado asíncrono)

Usos actuales de AJAX

  • Autocompletado de búsqueda (Google, buscadores de e-commerce)
  • Validación de formularios en vivo (ej. "este usuario ya existe")
  • Scroll infinito (redes sociales)
  • Carritos de compra que se actualizan sin recargar
  • Dashboards con datos en tiempo real
  • Toda aplicación SPA (ej. nuestro Menú Dinámico Uastiano, Vue 3)

Ejemplo de funcionamiento

Una solicitud AJAX real con fetch() contra una API pública (la misma que usamos en la Práctica 5.1):


boton.addEventListener('click', async () => {
  const respuesta = await fetch(
    'https://jsonplaceholder.typicode.com/posts/1'
  );
  const datos = await respuesta.json();

  document.querySelector('#resultado').textContent =
    datos.title;
  // La página nunca se recargó: solo cambió #resultado
});

Paso a paso de este ejemplo

  1. El usuario hace clic en un botón (evento).
  2. fetch() envía una solicitud GET asíncrona a la API.
  3. El servidor responde con un objeto JSON.
  4. await respuesta.json() convierte la respuesta en un objeto JS.
  5. Se actualiza únicamente el elemento #resultado del DOM.

En síntesis

XML, JSON y AJAX son tres piezas del mismo rompecabezas: XML y JSON son formatos para estructurar datos; AJAX es la técnica que usa JavaScript para transportar esos datos entre navegador y servidor sin recargar la página — el mismo principio detrás de toda aplicación web moderna que hemos construido en este laboratorio.
