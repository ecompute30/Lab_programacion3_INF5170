# Práctica 6 — Formatos de Transporte de Datos

Tres presentaciones hechas con [reveal.js](https://revealjs.com/), construidas con la skill
`/html-slides`, que resumen los tres formatos/técnicas de intercambio de datos más usados en
aplicaciones web:

| # | Tema | Carpeta |
|---|------|---------|
| 6.1 | XML | [`P6.1_XML/`](P6.1_XML/index.html) |
| 6.2 | JSON | [`P6.2_JSON/`](P6.2_JSON/index.html) |
| 6.3 | AJAX | [`P6.3_AJAX/`](P6.3_AJAX/index.html) |

[`index.html`](index.html) en la raíz de esta carpeta es un hub que enlaza a las tres.

## Contenido de cada presentación

Cada una cubre: qué es, su propósito, características principales, ventajas/desventajas,
comparación con otros formatos, usos actuales y un ejemplo comentado — tal como pide el
enunciado de cada tarea. Donde fue posible se usaron ejemplos reales de este mismo laboratorio
(el `menu.json` de la Práctica 4 en la presentación de JSON, y una llamada `fetch()` a
JSONPlaceholder —la misma API de la Práctica 5.1— en la de AJAX) para mostrar continuidad entre
prácticas en vez de ejemplos genéricos.

## Estilo

`uasd-theme.css` (compartido por las tres) reutiliza la paleta de colores y el logo de la UASD
ya usados en las prácticas 3 a 5, sobre el tema base `white` de reveal.js.

## Cómo navegar una presentación

Flechas / `Espacio` para avanzar, `Esc` para ver el resumen de todas las diapositivas, `S`
para el modo de notas del presentador.
