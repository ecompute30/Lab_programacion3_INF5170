¿Qué es JSON?

JSON (JavaScript Object Notation) es un formato ligero de texto para representar datos estructurados, basado en la sintaxis de los objetos literales de JavaScript, pero independiente de cualquier lenguaje.

Estandarizado como ECMA-404 / RFC 8259, hoy es prácticamente el idioma universal con el que las APIs web envían y reciben datos.

Propósito de JSON

  • Ofrecer un formato ligero y rápido de parsear para el intercambio de datos entre cliente y servidor.
  • Mapear de forma directa a las estructuras de datos nativas de la mayoría de los lenguajes (objetos, diccionarios, listas).
  • Simplificar el consumo de APIs REST, donde reemplazó en gran medida a XML/SOAP.

Características principales

Estructura

  • Pares clave: valor
  • Objetos { } y arreglos [ ]
  • Se pueden anidar libremente

Tipos de dato

  • string, number, boolean
  • null
  • Sin tipo nativo de fecha (se usa string)

Ventajas y desventajas

Ligero: menos caracteres que XML para el mismo datoNo admite comentarios

Usos actuales de JSON

  • APIs REST (ej. JSONPlaceholder, Rick and Morty API — las que usamos en la Práctica 5)
  • Bases de datos NoSQL (MongoDB)
  • Archivos de configuración: package.json, tsconfig.json
  • Apps móviles (respuestas de backend)
  • Almacenamiento local en el navegador
  • Nuestro propio menu.json del Menú Dinámico Uastiano

Ejemplo de objeto JSON

Extracto real de src/data/menu.json, Práctica 4:


{
  "menu": [
    {
      "id": 1,
      "nombre": "Inicio",
      "enlace": "/inicio",
      "icono": "🏠"
    }
  ]
}

Partes del objeto

  • Objeto raíz { }: contiene una clave "menu".
  • Arreglo [ ]: lista de opciones de menú, cada una un objeto.
  • Clave "id": siempre va entre comillas dobles.
  • Valor numérico 1: sin comillas, tipo number.
  • Valores de tipo string: "nombre", "enlace", "icono".

En síntesis

JSON ganó la mayoría de las APIs web modernas por ser liviano y nativo en JavaScript — pero en la Práctica 6.3 veremos cómo se usa en vivo, a través de AJAX, para traer estos datos sin recargar la página.
